# Downloads

The lecture notes and the exercise book in PDF, with the same numbering of definitions, theorems, examples and exercises as the website, the lecture slides and the Colab notebooks with the code of the algorithms. Text and figures are released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.en), the code under the MIT licence.
