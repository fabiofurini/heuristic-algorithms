# Heuristic Algorithms

Lecture notes on heuristic algorithms for combinatorial optimization problems: primal and dual bounds and the evaluation of heuristics, constructive heuristics, local search, metaheuristics (simulated annealing, tabu search, iterated local search, variable neighbourhood search, GRASP, large neighbourhood search, genetic algorithms) and MIP heuristics, applied to knapsack, bin packing, TSP, parallel machine scheduling and vertex coloring. With worked exercises, slides, interactive apps and Colab notebooks (Python and C++).

**Website: [fabiofurini.github.io/heuristic-algorithms](https://fabiofurini.github.io/heuristic-algorithms/)**

Prerequisites: [Combinatorial Optimization](https://fabiofurini.github.io/combinatorial-optimization/) (the problems, their instances and their formulations).

Part of the series *Operations Research and Mathematics* by [Fabio Furini](https://fabiofurini.github.io/) (DIAG, Sapienza University of Rome). Contents CC BY 4.0, code MIT.
